# SLICE POP
Игра для тренировки индексации и срезов Python. React / Vinext, Cloudflare D1.

Запуск: npm install, npm run db:generate, npm run dev.
Развёртывание выполняется через Sites; комнаты требуют привязанную D1 и применённые миграции.

Поддерживаются s[i], s[start:stop:step], отрицательные индексы, конкатенация и необязательный print(...). Произвольный код не исполняется. Учебный словарь ограничен и находится в lib/game.ts.

Дуэль: два игрока, код комнаты, пять минут с момента создания, собственные уникальные слова, 10 очков за букву. Регистрации внутри игры нет. Текущий хостинг Sites создаётся приватным и до смены доступа не подходит для приглашения внешнего друга.
