# Размещение STAR.exe на Spaceweb

Эта сборка предназначена для обычного виртуального хостинга с PHP 8.1+ и Apache. Node.js на сервере не нужен. Нужны стандартные JSON, PCRE, файловая система и random_bytes; MySQL, SQLite и mbstring не требуются.

## Что загрузить

В репозитории уже есть готовая папка `deploy/spaceweb`:

```text
deploy/spaceweb/
  public_html/           ← корень сайта, доступный через домен
    index.html           ← главная
    assets/              ← общий логотип
    game/                ← игра со словами
    turtle/              ← актуальная Черепаха
    records/13-tcp-ip/    ← запись «13 задание. TCP/IP»
    api/game/index.php   ← вход в сервер комнат
    .htaccess
  server/                ← PHP-логика, словарь; вне корня сайта
  storage/               ← комнаты, создаются автоматически; вне корня сайта
```

1. Добавьте сайт/домен в панели Spaceweb и выберите PHP 8.1 или новее.
2. Через файловый менеджер или SFTP загрузите `public_html`, `server` и `storage` в одну папку сайта, сохраняя их взаимное расположение. Загружайте содержимое репозитория, а не страницы из ссылок Sites.
3. Корнем домена должна быть именно папка `public_html`. Если Spaceweb создал корневую папку с другим именем, поместите содержимое `public_html` туда, а `server` и `storage` расположите рядом с ней, на один уровень выше публичных файлов. Обработчик API вычисляет путь к ним относительно своей папки.
4. Включите HTTPS. Для `crypto.randomUUID()` в браузере нужен защищённый контекст. Домен указывается в панели; прописывать его в коде не требуется.
5. Убедитесь, что PHP может писать в `storage`. Начните с прав 755; если PHP работает от другой группы, настройте 775 с подходящей группой. Не назначайте 777 всему сайту.
6. Не загружайте тестовые `storage/rooms.json`, `.lock`, `.tmp`: на сервере они появятся сами. Не делайте `server` или `storage` корнем домена.
7. Откройте главную, игру, Черепаху и запись. Создайте комнату в одном браузере и подключитесь по коду в другом. Проверьте слово `s[12:14]+s[9:11]`: «фото», 60 очков.

Если путь к частной папке ограничен настройкой open_basedir, включите папку сайта целиком (public_html вместе с соседними server/storage) в разрешённые пути через панель или поддержку Spaceweb.

Все страницы доступны под одним доменом, ссылки относительные к корню. Установка в подпапку вида example.ru/starexe не предусмотрена этой сборкой.

## Как пересобрать после изменений

На своём компьютере:

```sh
npm install
npm run build
```

Исходники по-прежнему лежат в `apps/`. PHP-сервер: `spaceweb/server`. Сборщик `scripts/build-spaceweb.mjs` формирует готовую папку `deploy/spaceweb`. Старые папки `apps/*/.openai` относятся к Sites и на Spaceweb не загружаются.

Локальная проверка (PHP в PATH и Python 3):

```sh
npm run test:spaceweb
```

Тесты создают локальные комнаты в deploy/spaceweb/storage; они исключены из Git. Существующие комнаты Cloudflare D1 в новый файловый сервер не переносятся. Новые комнаты действуют 5 минут; старые удаляются при запросах через сутки. При больших нагрузках файловое хранилище следует заменить на базу данных.

Копируйте на хостинг только `deploy/spaceweb`, а не `.git`, `node_modules`, `.build` и служебные исходники. Обновляя файлы сайта, сохраняйте рабочий `storage/rooms.json`, если не хотите сбрасывать комнаты.
